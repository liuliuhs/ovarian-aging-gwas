# Input data

No input datasets are bundled in this collection.

Consult SCRIPT_INPUTS.md for file and worksheet references extracted from the
scripts. Obtain upstream GWAS, FUMA, MAGMA, TWAS, colocalization, GTEx and
prioritization outputs as appropriate, and document their versions and sources.
Some scripts use historical supplementary workbooks with earlier table
numbers. Check worksheet and column names before using a different workbook.

The gene-prioritization script additionally relies on intermediate RData files
and pre-existing objects. Their generating scripts and data are not included.
