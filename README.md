# Ovarian aging GWAS

Analysis and plotting scripts accompanying the manuscript
"Multivariate genetic analysis reveals shared architecture and candidate genes for ovarian aging".

## Scripts

genePrioritization_cleaned.R: integration of genetic and functional evidence for candidate gene prioritization.

## Requirements

R and the packages listed in each script are required.
Software versions and input data descriptions will be added before public release.

## Current status

The repository is being prepared for public release.
The gene prioritization script currently retains local file paths and dependencies on intermediate files and existing R objects.
